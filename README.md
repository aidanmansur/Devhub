# DevHub 🚀

DevHub is a GitHub-inspired developer platform built with HTML, CSS and JavaScript.

The project was created to practice and demonstrate frontend development concepts such as DOM manipulation, localStorage, form validation, dynamic UI rendering, project management and user interactions.

## ✨ Features

- 🔐 User Registration & Login
- 👤 User Profile
- 📝 Edit Profile Information
- 📁 Create Projects
- ✏️ Edit Projects
- 🗑️ Delete Projects
- 🔎 Search Projects
- 🏷️ Filter Projects by Programming Language
- 📖 README Editor & Markdown Preview
- ⭐ Star Projects
- 🍴 Fork Projects
- 📊 Project Statistics
- 📈 Profile Statistics
- 🔗 GitHub & Demo Links
- 💾 LocalStorage-based Data Management
- 📱 Responsive Design

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- LocalStorage
- DOM API
